# SINURMAN

Sistem Informasi Nurul Iman adalah demo aplikasi manajemen pesantren terpadu
untuk pengurus, ustadz, dan wali santri.

## Fitur

- Dashboard perkembangan santri
- Tahfidz dan setoran hafalan
- Mutaba’ah ibadah
- Kesehatan santri
- Uang saku dan pembayaran SPP
- Rapor karakter
- Data santri dan inventaris
- Pengumuman dan laporan
- Demo pergantian peran Admin, Ustadz, dan Wali Santri
- Mode terang/gelap serta tampilan responsif

## Pengembangan

Gunakan `npm run dev` untuk menjalankan aplikasi dan `npm run build` untuk
memvalidasi hasil produksi.
